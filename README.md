\# DevPath — Programming Learning and Placement Preparation Portal



DevPath is a web application built with Spring Boot to help learners explore programming courses and prepare for placements.



\## Features



\- Home page introducing DevPath

\- Courses page featuring Java, Python, and Web Development

\- Responsive web page design

\- Automated build and deployment using Jenkins and Docker



\## Technologies Used



\- Java 21

\- Spring Boot

\- Maven

\- Git and GitHub

\- Jenkins

\- Docker



\## Project URLs



When the application is running locally:



\- Home: http://localhost:8083/

\- Courses: http://localhost:8083/courses



\## Build the Project



Open Command Prompt in the project directory and run:



```cmd

mvnw.cmd package

```



\## CI/CD Pipeline



The Jenkins pipeline checks out code from GitHub, builds the application with Maven, creates a Docker image, deploys the container, and verifies the application.



\## Project Goal



To build a programming learning portal while gaining practical experience with Java, Git, Jenkins, Maven, and Docker.
